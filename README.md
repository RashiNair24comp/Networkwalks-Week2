# Networkwalks Cybersecurity Internship – Week 2

This repository contains my documentation and screenshots from Week 2 of the Networkwalks Cybersecurity Internship.

## Project Modules

| Module | Topic | Tool |
|---|---|---|
| Module 1 | Web Technology & WAF Detection | WhatWeb, WAFW00F |
| Module 2 | Google Hacking Database (GHDB) | Google Search |
| Module 3 | OSINT & Information Gathering | Maltego |
| Module 4 | Footprinting & Reconnaissance | theHarvester |
| Module 5 | Network Scanning | Zenmap |

## Repository Structure

Each module folder contains:
- `Documentation` – Notes and activity summaries.
- `Screenshots` – Screenshots documenting the work performed.

## Learning Outcomes

- Learned about web technology identification and WAF detection.
- Explored Google Hacking Database search techniques.
- Practised visual OSINT concepts using Maltego.
- Reviewed theHarvester commands and reconnaissance concepts.
- Explored network scanning and host discovery using Zenmap in an isolated lab environment.

## Note

All activities were performed for educational purposes. Privacy-sensitive information and raw network scan data have been excluded from this public repository.
